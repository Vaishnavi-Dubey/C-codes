## ✨ Key Features

- 📘 **100+ Programs** — Extensive collection covering the full spectrum of C/C++ fundamentals
- 🔢 **Variables & Constants** — Deep exploration of data types, constants (`const`, `#define`), and memory
- ➕ **Operators Mastery** — Arithmetic, logical, bitwise, shift, XOR, AND, OR, and complement operators
- 📊 **Arrays** — Array initialization, subscript operations, and multi-dimensional arrays
- 💻 **Binary Representation** — Programs for binary conversion and bit-level manipulation
- 🔄 **C vs C++ Comparison** — Many concepts implemented in both C and C++ for cross-language understanding

## 🏗️ Architecture / How It Works

Programs are numbered sequentially (`01_` to `119+`) following a structured curriculum path:

```
Variables & I/O (01-10) → Data Types (11-30) → Operators (31-70)
→ Logical & Bitwise (71-116) → Arrays (117-119+)
```

Each file is a **standalone program** that compiles and runs independently, making it easy to study individual concepts.

```
C-codes/

├── 118_arrayInitialisation.c        # Array initialization patterns
```

## ⚙️ Installation & Setup

```bash
# Clone the repository
git clone https://github.com/Vaishnavi-Dubey/C-codes.git
cd C-codes

# Ensure GCC/G++ is installed
gcc --version
g++ --version
```

---

## ▶️ Usage

### Compile & Run a C program:
```bash
gcc 02_HelloWorld.c -o hello
./hello
```

### Compile & Run a C++ program:
```bash
g++ 100_LogicalOR.cpp -o logical_or
./logical_or
```
